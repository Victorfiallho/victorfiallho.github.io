# Project Portfolio Page

This repository now includes a simple static portfolio page for hosting and showcasing your finished projects.

## Files added

- `index.html` – main portfolio page
- `styles.css` – page styling and layout

## How to use

1. Add more project cards directly in `index.html`.
2. Update the descriptions to highlight each project.
3. Commit and push the repository.

## Hosting

To host this page publicly, use GitHub Pages:

1. Push the repo to GitHub.
2. In GitHub, enable Pages for the `main` branch.
3. Select the repository root as the publishing source.

Once enabled, your portfolio page will be served from your GitHub Pages URL.
